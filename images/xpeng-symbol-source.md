# XPeng symbol

Source: `xpeng-logo.svg`, the original [XPeng investor-relations logo](https://ir.xiaopeng.com/sites/g/files/knoqqb75791/themes/site/nir_pid7769/dist/images/logo.svg).

[Wikimedia Commons](https://commons.wikimedia.org/wiki/File:XPeng_logo.svg) identifies the original geometric/text logo as public domain (`PD-textlogo`).

`xpeng-symbol.svg` retains the original two symbol subpaths, removes the wordmark, and uses a tight viewBox. The geometry and black fill are unchanged. The original complete logo is preserved. The derived symbol is used to identify XPeng in this homepage's employment history.
